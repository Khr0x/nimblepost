# Code of conduct

NimblePost welcomes contributors and users of all experience levels and
backgrounds. This policy applies to project issues, pull requests, reviews,
and other interactions in project spaces.

## Expected behavior

- Treat people with respect. Give feedback about the work and explain how
  someone can act on it.
- Make room for questions, different viewpoints, and disagreement.
- Respect privacy and ask before sharing someone else's private information.

Harassment, threats, discriminatory remarks, unwanted sexual attention, and
sharing private information without consent are unacceptable.

## Reporting and moderation

Use [GitHub's abuse reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
If GitHub offers **Report to repository admins**, use it to reach project
maintainers. The GitHub Support reporting form is also available. Include a
link to the relevant interaction and share sensitive details only through
the private reporting channel.

Maintainers may remove content, limit participation, or block accounts to
protect the project community. They will handle reports discreetly and
share details only as needed to respond.
